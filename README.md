# 偷偷吃草 3D · 自由牧场

真实 WebGL 3D 卡通奶牛网页小游戏，包含自由跑动、跟随相机、青草采集、农场主巡查、障碍物碰撞和视线遮挡。公开页面无需 ChatGPT / GPT 账号登录，打开链接即可玩。

## 运行

需要 Node.js 18 或更新版本，以及支持 WebGL 2 的浏览器。

```sh
npm install
npm start
```

打开 http://127.0.0.1:4173 。使用 Ctrl+C 停止本地服务器。运行文件已经保存在 `dist/`，下载项目后即使不安装依赖，也可以直接 `npm start` 运行；`npm install` 用于更新或重新生成 Three.js 运行模块。

```sh
npm test
npm run check
```

## 操作

| 操作 | 桌面 | 手机 |
| --- | --- | --- |
| 自由移动 | WASD 或方向键 | 左下角摇杆 |
| 冲刺 | 按住 Shift | 切换「跑起来」按钮 |
| 吃草 | 靠近青草后按住空格 | 长按右下角吃草按钮 |
| 转动视角 | 拖动画面，或 Q / E | 在画面上拖动 |
| 缩放 | 鼠标滚轮 | 默认跟随视角 |
| 重置视角 | R 或相机按钮 | 相机按钮 |
| 暂停 / 继续 | P 或暂停按钮 | 暂停按钮 |
| 全屏 | 全屏按钮 | 浏览器支持时使用全屏按钮 |

按住吃草时奶牛会停下，草丛周围出现黄色圆环表示已经进入采集范围。切换窗口、隐藏页面或打开说明会暂停游戏并释放全部输入。

## 两种模式

**自由漫游**：没有倒计时，也不会因为被看见而失败。可以探索牧场、练习移动和吃草，每片青草有3束，吃完7秒后重新生长。

**偷吃挑战**：三关分别需要在90 / 100 / 110秒内吃完12 / 16 / 20束青草。每束10分，完整通关480分。每片牧场有54束青草，过关会重置位置、青草和怀疑值。

农场主会在牧场内走动，阶段为忙碌（绿色）、回头预警（黄色）、巡查（红色）。黄色预警持续1.15 / 0.95 / 0.8秒，之后出现约104度、半径9.5米的视野扇形。

巡查时，在视野中跑动或吃草，每秒增加60%怀疑值；静止、离开视野或躲到遮挡物后，每秒降低16%。满100%或倒计时结束则失败。树干、草垛、牛棚和水槽会阻挡移动及视线；灌木可进入并藏身。最佳挑战分数只保存在当前浏览器。

## 技术实现

- HTML / CSS / ES Modules，无后端和账号系统。
- Three.js 0.186.1，使用 WebGLRenderer、透视相机、立体几何模型、光照和实时阴影。
- 奶牛和农场主由本地几何体构建，包括腿部跑动、头部吃草、尾巴摆动和铃铛。
- Three.js模块及MIT许可放在 `dist/vendor/`，运行时无需访问外部CDN。
- Web Audio可选音效、Pointer Events摇杆和多点触控、localStorage成绩、全屏与WebGL丢失提示。
- 不支持WebGL 2时显示明确提示，不会显示一个没有反应的开始按钮。

## 螺旋模型开发记录

### 第一轮：空间玩法

将原先仅按住 / 松开的2D玩法升级为空间牧场。先完成纯逻辑的二维地面坐标、标准化移动、冲刺、边界、碰撞和采集范围，避免斜向加速、穿过障碍以及站在远处也能吃草。

### 第二轮：真实3D与巡查

加入立体奶牛、农场主、牛棚、树木、草垛、青草和牧场小地图；相机跟随位置，移动方向相对于相机。视野判定结合角度、距离和线段遮挡，提供可见的视野扇形和灌木藏身反馈。

### 第三轮：两种模式与适配

加入不计时的自由漫游和三关挑战，重新增加寻找青草所需的关卡时间；完成桌面键盘、拖动相机、手机摇杆与吃草按钮、暂停和页面失焦处理。页面使用公开访问策略，去掉原先的登录门槛。

## 验证

14项核心自动测试覆盖：移动及斜向速度、冲刺、边界、碰撞、距离采集、草丛数量和再生、未完成采集进度、视野角度及距离、遮挡和藏身、静止安全及怀疑恢复、暴露失败、暂停、漫游与超时、三关480分及重置、无效输入。

浏览器实测：WebGL成功渲染；自由漫游吃草、W移动、Q转视角及P暂停；桌面及手机尺寸布局和输入。移动端通过浏览器视口检查，实际设备的帧率仍取决于设备GPU。

## 文件

- `dist/engine.js`：关卡、牧场数据、移动碰撞、青草及巡查规则。
- `dist/world.js`：Three.js场景、角色模型、光照、阴影、相机和动画。
- `dist/main.js`：输入控制、音效、HUD、小地图、暂停和模式选择。
- `dist/style.css`：桌面和手机布局。
- `scripts/vendor.mjs`：复制已锁定的Three.js运行模块及许可。
- `server.mjs`：本地静态服务器。
- `tests/engine.test.mjs`：14项核心规则测试。
