# Crazy Cow · 疯狂奶牛牧场

真实WebGL 3D卡通奶牛小游戏：自由跑动、吃随机青草、冲撞饲养员、挑战隐藏路线、收集成就。

[直接游玩](https://finn-307.github.io/crazy-cow/) · [更新日志](CHANGELOG.md) · [界面设计记录](DESIGN.md)

通过GitHub Pages项目子路径部署，无需登录；所有运行模块本地加载。

## 本地运行

需要Node.js 18或更新版本，以及支持WebGL 2的浏览器。

```sh
npm install
npm start
```

打开 http://127.0.0.1:4173 。Ctrl+C停止服务器。`dist/`已含Three.js模块，也可直接用`npm start`预览。

```sh
npm test
npm run check
npm run privacy
```

## 三档难度

开局选择难度；挑战模式依次完成三关，自由漫游可选择任意地图且不计时。漫游仍保留该难度的冲撞追赶与暴怒。

| 难度 | 三关青草目标 | 三关时间 | 隐藏声阻触发 | 平常藏身逃脱 |
| --- | --- | --- | --- | --- |
| 悠闲 | 9 / 14 / 18束 | 142 / 162 / 182秒 | 本关撞中4次 | 1.6秒 |
| 标准 | 12 / 18 / 24束 | 105 / 120 / 135秒 | 本关撞中3次 | 2.2秒 |
| 硬核 | 15 / 23 / 30束 | 84 / 96 / 108秒 | 本关撞中2次 | 2.8秒 |

难度还影响巡查预警、视野、怀疑增长、追赶速度与时长。悠闲的巡查视野半径11，标准13，硬核16；3D视野扇形和实际判定保持一致。

标准模式每秒增加60%怀疑，悠闲42%、硬核76%；站住或离开视野每秒降低18%。满100%失败。草垛、树木、水塘、牛棚及岩石阻挡移动和视线，灌木可藏身。

## 随机青草

| 种类 | 颜色 | 吃一束的效果 |
| --- | --- | --- |
| 普通草 | 绿 | 10分 |
| 苜蓿 | 淡紫 | 10分，额外降低12%怀疑 |
| 黄金草 | 金黄 | 30分 |
| 薄荷草 | 青绿 | 10分，移动加速20%持续6秒 |

初始草丛部分位置随机偏移，品种随机分配。被吃完后，悠闲等待7～11秒、标准8～14秒、硬核11～17秒，在地图内重新随机选择位置和品种；刷新避开地标、水塘、边界及其他活跃草丛。没有安全位置时稍后重试，不强行生成。挑战与漫游都能再生。

普通草是主要来源，特殊草提供额外策略；HUD显示附近品种和效果，小地图按品种着色。剩余再生时间不足2秒时出现嫩芽。薄荷加速也影响冲撞。

## 冲撞、声阻与隐藏通关

奶牛行走速度8、冲刺13.5；F/冲撞按钮沿当前移动方向或朝向冲出，速度27、持续0.32秒、冷却3秒。普通命中使饲养员眩晕0.8秒，随后追赶，障碍寻路会绕开地标。

**声阻**是饲养员的隐藏称号。本关达到该难度的冲撞阈值后，他进入暴怒：追赶速度提高18%、时长延长25%、藏身逃脱时间增加40%；眩晕缩短至0.55秒。暴怒期间会显示0.6秒的红色瞄准预警，然后沿瞄准方向短暂冲锋，可以横向闪避。逃脱后这次暴怒结束，称号发现记录留在图鉴；再次惹怒仍可触发。

**隐藏路线**：同一关完成三次独立的冲撞追逐，并且每次成功逃脱，即可不靠吃满青草通关。第三关也可这样完成整次挑战。同一场追赶连续撞多次，最后逃脱只算一次。追赶未结束时不能直接过关。本关逃脱进度进入下一关会重置。

自由漫游可以反复冲撞与逃脱，但不会自动结算关卡。被追到仍然失败。距离饲养员不足1.3会被抓；藏好规定时间或坚持到追赶计时结束都能逃脱。

## 成就与存档

「牧场日记」有12项成就：首次吃草、累计100束、5束黄金草、薄荷期间冲撞、首次撞击、首次逃脱、隐藏通关、声阻现身、暴怒逃脱、三图巡游、完成挑战及硬核全关。

解锁时出现通知，重复事件不会重复解锁。日记记录各难度最佳成绩和隐藏称号图鉴。存档只在当前浏览器，不跨设备同步；旧版本最佳分数迁移到标准档。清除浏览器数据会重置存档；存储不可用时仍可游玩。

## 动画与验证

奶牛采用膝部关节、慢跑与快跑步态、头部起伏、身体前倾、尾巴摆动及冲刺扬尘。饲养员采用髋部、膝部、摆臂、工具跟随、追赶前倾和暴怒蓄力动作。动画由实际移动距离驱动，撞墙时不会空跑；暂停保持关节姿势，减少动态效果偏好下省略夸张动作和扬尘。

40项自动测试覆盖原有玩法以及难度参数、随机刷新安全位置、特殊青草、隐藏路线贯穿三关、暴怒预警冲锋、成就去重、损坏存档恢复、分难度成绩与步态。

浏览器验证覆盖桌面和手机尺寸、难度预览与开局、吃草解锁成就、刷新恢复日记、移动和NPC步态标记。手机检查使用浏览器视口，尚未做iOS/Android实机验证。

## 隐私与发布

GitHub使用单独整理的源码和通用提交身份，排除个人路径、旧部署标识、凭据、环境变量文件、私钥和日志，保留Three.js的MIT许可。

`.github/workflows/pages.yml`在推送main后运行测试、语法及隐私检查，再部署`dist/`到`/crazy-cow/`。资源使用相对路径，不依赖域名根目录。

## 主要文件

- `dist/engine.js`：移动、关卡、采集、巡查、冲撞及隐藏路线。
- `dist/rules.js`：难度与青草规则、安全刷新位置。
- `dist/progress.js`：成就、称号记录和存档。
- `dist/gait.js`：关节步态。
- `dist/world.js`：立体场景、角色、动画、特效与相机。
- `dist/main.js`：输入、HUD、模式、日记、难度及通知。
- `tests/`：40项核心测试。
