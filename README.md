# Crazy Cow · 疯狂奶牛牧场

一款真实WebGL 3D卡通奶牛小游戏：自由跑动、偷偷吃草、冲撞饲养员，然后在更大的牧场中逃脱追赶。

- [直接游玩](https://finn-307.github.io/crazy-cow/)
- [更新日志](CHANGELOG.md)
- [界面设计记录](DESIGN.md)

网页通过GitHub Pages项目子路径部署，无需账号登录。不是账号根站点仓库。

## 运行

需要Node.js 18或更新版本，以及支持WebGL 2的浏览器。

```sh
npm install
npm start
```

打开 http://127.0.0.1:4173 。用Ctrl+C停止服务器。`dist/`已包含Three.js运行模块，直接运行`npm start`也可以预览现有版本。

```sh
npm test
npm run check
npm run privacy
```

## 操作

| 动作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD或方向键 | 左下角摇杆 |
| 冲刺 | 按住Shift | 切换「跑起来」 |
| 冲撞 | F | 黄色冲撞按钮 |
| 吃草 | 靠近青草后按住空格 | 长按绿色吃草按钮 |
| 转动相机 | 拖动画面，或Q/E | 拖动画面 |
| 缩放 | 鼠标滚轮 | 默认跟随相机 |
| 暂停/继续 | P或暂停按钮 | 暂停按钮 |
| 重置视角 | R或相机按钮 | 相机按钮 |
| 全屏 | 全屏按钮 | 浏览器支持时使用全屏按钮 |

移动方向相对于相机。松开吃草会立即停止；部分进度保留。切换窗口、隐藏页面或打开说明会暂停并释放全部输入。

手机有独立竖屏和横屏布局，考虑安全区域和多指输入。游戏区域及所有控件子元素禁用文字选择、系统长按菜单和拖拽，说明对话框仍可正常阅读。

## 三张独立地图

| 地图 | 可移动范围 | 特点 | 挑战目标 | 时间 |
| --- | --- | --- | --- | --- |
| 晨光大牧场 | 52×44 | 牛棚、草垛、大片草地 | 12束 | 105秒 |
| 苜蓿果园 | 60×52 | 苹果树阵列、水塘、果园小路 | 18束 | 120秒 |
| 落日风车谷 | 68×56 | 动态风车、岩石、秋色树木 | 24束 | 135秒 |

地图面积约为2.0版的4～6.7倍。每关分别配置不同出生点、青草、障碍、灌木、巡逻路线、道路和配色，均有90束可采集青草。

**偷吃挑战**从第一关开始，按顺序解锁地图。每束10分，标准目标累计540分；怀疑满100%或时间耗尽失败。处于追赶中时，先逃脱才能过关。

**自由漫游**可在开始菜单选择任何地图，没有倒计时和普通巡查失败，青草吃完7秒后再生。冲撞仍会触发追赶，被追上同样失败。

## 冲撞与追赶

- 冲撞持续0.32秒，速度27；每3秒可再次使用。按住移动方向后冲撞会沿该方向出发，否则沿当前朝向。
- 撞中饲养员后，他会眩晕0.8秒，然后追赶15/18/21秒。
- 饲养员使用路径规划绕开障碍，追赶速度9.2/10.2/11.2。奶牛行走速度8，冲刺速度13.5。
- 冲刺、绕过草垛并进入灌木；藏好2.2秒可以提前逃脱。饲养员追踪最后看见的位置，不会直接透视灌木中的奶牛。
- 距离饲养员不到1.3时会被抓。坚持到追赶计时结束也会脱离追赶。

## 普通巡查

绿色表示忙碌，黄色预警持续1.15/0.95/0.8秒，然后出现红色视野扇形，角度约104度，半径13。

在视野里跑动或吃草，每秒增加60%怀疑值；站住、离开视野或躲到障碍后，每秒下降18%。固体地标阻挡移动和视线；灌木可进入藏身。

## 技术与验证

- HTML/CSS/ES Modules + Three.js 0.186.1，无后端或账号系统，模块本地加载。
- 奶牛采用贴合身体的黑白斑纹、大眼睛、粉色鼻头、牛角、铃铛和动作表情。
- 静态场景通过InstancedMesh合并绘制；相机跟随更快，设备像素比有上限。
- 输入事件变化前按真实时间补算逻辑，避免低帧率时短按移动丢失；逻辑以最多20ms步长处理碰撞与巡查。
- 22项自动测试覆盖地图差异、速度、碰撞、采集、巡查、冲撞、冷却、眩晕、追赶、路径规划、逃脱、暂停、过关和重置。
- 浏览器检查覆盖1280×900桌面、390×844竖屏、844×390横屏；已实际操作冲撞命中、追赶提示、短按移动和1.6秒长按吃草。长按未选中文字，控件及子元素均为`user-select:none`。
- 手机检查使用浏览器视口，尚未在实际iOS/Android设备上验证。

## 隐私与发布

上传到GitHub的是单独整理的源码和干净提交历史：排除旧部署标识、本地绝对路径、环境变量文件、日志、私钥和身份凭据；提交身份使用通用贡献者名称及noreply邮箱。

`npm run privacy`检查可发布源码，`scripts/export-github.mjs`按允许名单导出到本地忽略目录。Three.js的MIT许可保存在`dist/vendor/THREE-LICENSE.txt`，不会删去第三方必要版权信息。

`.github/workflows/pages.yml`在推送到main时运行测试、语法和隐私检查，通过后部署`dist/`到项目子路径。所有资源使用相对路径，不依赖域名根目录。

## 文件

- `dist/maps.js`：三张地图配置。
- `dist/engine.js`：关卡、移动、碰撞、青草、巡查、冲撞与追赶。
- `dist/navigation.js`：饲养员障碍寻路。
- `dist/world.js`：立体场景、实例化、角色、相机、光照和动画。
- `dist/main.js`：输入、音效、HUD、小地图、模式选择和暂停。
- `dist/style.css`：桌面、手机竖屏及横屏布局。
- `tests/engine.test.mjs`：22项核心测试。
- `scripts/privacy-check.mjs`：源码隐私检查。
